# Evaluasi Pekan 5 — Kedai Senja

Program latihan JavaScript dasar untuk mengelola data menu, menghitung transaksi dan
laporan harian, memperbaiki bug, serta bereksperimen dengan coercion dan cakupan variabel.

## Cara menjalankan

Buka `index.html`, `perbaikan.html`, atau `eksperimen.html` di browser. Buka Developer
Tools (biasanya F12) dan pilih tab **Console** untuk melihat keluaran masing-masing
program. Setiap halaman hanya memuat file JavaScript miliknya sendiri.

## Teknologi

- HTML5
- JavaScript (tanpa library atau framework)
- Git dan GitHub

Jalankan `git blame index.html` dan catat hash commit serta nama author yang terakhir

## Jawaban Git

- `git add` menyiapkan perubahan ke staging area; `git commit` menyimpan snapshot dari
  perubahan yang sudah di-stage ke riwayat repository.
- Konflik terjadi ketika dua branch mengubah bagian yang sama secara berbeda. Penyelesaian
  dilakukan dengan memilih atau menggabungkan isi yang benar, menghapus penanda konflik,
  menguji hasilnya, lalu membuat merge commit.
- `clone` menyalin repository ke komputer lokal. `fork` membuat salinan repository di akun
  GitHub sendiri. Pull Request mengusulkan perubahan dari satu branch/repository ke branch
  tujuan untuk ditinjau dan digabung.

## Branch dan Pull Request

Bagian 2–5 dikerjakan pada branch masing-masing sesuai instruksi evaluasi. Bagian 5 perlu
digabungkan melalui Pull Request `docs/tebak-jelaskan` ke `main`. Bukti log/blame, status
PR, serta sinkronisasi remote harus diisi menggunakan riwayat dan repository GitHub aktual;
